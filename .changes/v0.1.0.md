## v0.1.0 - 2026-04-11


#### Added

##### Add documentation example for custom codecs.

##### Add `PayloadTooLarge` error variant to `DecodeError`.


#### Changed

##### Clarify canonical encoding contract (integers use smallest format; floats always use float64). Document stability guarantees for all error types.

##### Mark `encode` and `decode` modules as internal. Use `pack`, `unpack`, and `unpack_exact` from the main `msgpack_gleam` module instead.


#### Performance

##### Optimize object decoding from O(N^2) to O(N) by using intermediate Dict lookup.


#### Security

##### Prevent integer overflow and memory exhaustion DoS attacks

Added maximum size limits for strings (128MB), binaries (128MB), and collections (4M elements) to prevent DoS attacks via massive length prefixes.
